# Group 2: Next-Status Prediction Experiments

Six configurations each of logistic regression and random forest were compared on a shared split: 233,185 training rows and 700,403 validation rows.

## Selected model

`group2_w2_exp06_rf`: 48 trees, maximum depth 10, seed 12345. Validation log loss (`h_fg`) is 0.153104411. The report discusses feature-group diagnostics and the limitations of selecting a model when the final evaluation distribution differs.

## Submission files

- `models/group2_w2_exp06_rf_model/`: complete saved Spark PipelineModel. Preserve every file and subdirectory.
- `initialExample_experiments.zpln`: exported Zeppelin notebook.
- `Experiment_Report.pdf`: two-page English report.

## Reproduce the workflow

Use a compatible Spark/Zeppelin environment (the experiments used Spark 3.5.9 and Zeppelin 0.12.1). Create a project directory with the supplied training data at `data/training_data/`, and copy the complete selected model to `models/group2_w2_exp06_rf_model/`. Import the notebook, set **base folder** to that project directory and **group name** to `group2_w2_exp06`, then run from top to bottom.

Existing models are loaded with their saved parameters. Missing models are trained using the corresponding preset; therefore a full run may also train the LR model. Historical comparisons skip experiments that are unavailable. The training data are not included in this repository.

For inference only, load the saved model from its actual location with `PipelineModel.load` and provide compatible evaluation inputs. No training-data reload is required.
